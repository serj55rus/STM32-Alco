    КОМПОНЕНТЫ:

    R1 = 4.7 кОм (подтягивающий резистор для DS18B20)
    R2 = 220 Ом (токоограничивающий резистор для LED)

    DS18B20:    1 - GND, 2 - Data, 3 - VCC (3.3V)
    LCD I2C:    Адрес 0x27
    Кнопка:     Нормально разомкнутая, без фиксации
    Клапан:     Подключается через релейный модуль


    ПРИМЕЧАНИЯ ПО ПОДКЛЮЧЕНИЮ КЛАПАНА:

    Выход PA1 (3.3В) не может напрямую управлять мощным клапаном!
    Используйте один из вариантов:

    Вариант 1: Релейный модуль
      PA1 → IN релейного модуля
      GND → GND релейного модуля
      5V  → VCC релейного модуля
      COM → Фаза клапана
      NO  → Клапан

    Вариант 2: MOSFET транзистор
      PA1 → Затвор (через резистор 100 Ом)
      Сток → Клапан
      Исток → GND

    Вариант 3: Оптопара + симистор
      Для управления сетевым напряжением 220В
