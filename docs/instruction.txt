================================================================================
                    КОНТРОЛЛЕР КЛАПАНА ДИСТИЛЛЯТОРА
                         Модель: VC-STM32 v1.0
================================================================================

                         НАЗНАЧЕНИЕ УСТРОЙСТВА
--------------------------------------------------------------------------------
Контроллер предназначен для автоматического управления клапаном отбора 
дистиллята на основе показаний датчика температуры DS18B20. Устройство 
поддерживает режим стабилизации температуры и автоматический отбор продукта.

================================================================================
                       ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ
================================================================================

Микроконтроллер:     STM32F401CCU6 (Black Pill)
Датчик температуры:  DS18B20 (цифровой, 1-Wire)
Дисплей:             LCD 16x2 символов (I2C, адрес 0x27)
Управление:          1 кнопка (PB3) с функцией короткого/длинного нажатия
Выход управления:    PA1 (цифровой выход 3.3В)
Питание:             5В через USB или внешний источник
Потребляемый ток:    до 100 мА (без учета клапана)

Параметры по умолчанию:
  - Целевая температура: 30°C
  - Гистерезис: 0.5°C
  - Таймер стабилизации: 20 секунд
  - Максимальная температура настройки: 80°C

================================================================================
                       ПОДКЛЮЧЕНИЕ КОМПОНЕНТОВ
================================================================================

  STM32F401CCU6 (Black Pill):
  ┌─────────────────────────────────┐
  │                                 │
  │  PA1  ──── Клапан (Valve)       │
  │  PA3  ──── DS18B20 (Data)       │
  │  PB3  ──── Кнопка (Button)      │
  │  PB6  ──── LCD SCL              │
  │  PB7  ──── LCD SDA              │

  │  3.3V ──── Питание DS18B20      │
  │  GND  ──── Общий провод         │
  │  PC13 ──── Светодиод (LED)      │
  │                                 │
  └─────────────────────────────────┘

================================================================================
                         ОРГАНЫ УПРАВЛЕНИЯ
================================================================================

КНОПКА (PB3):
  - КОРОТКОЕ нажатие (< 2 сек): Подтверждение / Увеличение значения
  - ДЛИННОЕ нажатие (> 2 сек):  Переход в меню / Возврат / Выход

СВЕТОДИОД (PC13):
  - Мигает 1 раз в секунду: Нормальная работа
  - Мигает быстро: Аварийный режим (если активирован)

================================================================================
                       РЕЖИМЫ РАБОТЫ
================================================================================

1. WAIT (Главный экран) - Режим ожидания
   ┌────────────────────┐
   │ Temp: 25.3 C       │
   │ Wait! Press BTN    │
   └────────────────────┘
   • Отображает текущую температуру
   • Короткое нажатие: Запуск стабилизации (STABILIZATION)
   • Длинное нажатие:  Вход в настройки гистерезиса (SET_UP)

2. SET_UP (Настройка гистерезиса)
   ┌────────────────────┐
   │ Gysteresis   0.5   │
   │ Press BTN +0.5     │
   └────────────────────┘
   • Короткое нажатие: Увеличение гистерезиса на 0.5°C
     (после 3.0 сбрасывается на 0.5)
   • Длинное нажатие:  Возврат в WAIT

3. STABILIZATION (Стабилизация)
   ┌────────────────────┐
   │ Wait stable...     │
   │ 25.3 <> 30.0      *│
   └────────────────────┘
   • Отображает текущую и целевую температуру
   • * мигает показывая активность системы
   • Автоматически переходит в TIMER_STAB при достижении целевой температуры
   • Длинное нажатие: Переход в SET_TARGET

   ПРИМЕЧАНИЕ: Управление нагревом должно осуществляться 
   ВНЕШНИМ регулятором мощности (РМВ/симистор)!

4. SET_TARGET (Установка целевой температуры)
   ┌────────────────────┐
   │ Target temp   30   │
   │ Press BTN max 80   │
   └────────────────────┘
   • Короткое нажатие: Увеличение температуры на 1°C
     (после 35°C сбрасывается на 30°C)
   • Длинное нажатие:  Возврат в STABILIZATION

5. TIMER_STAB (Таймер стабилизации)
   ┌────────────────────┐
   │ Stabilization..    │
   │ 00:20 T:30.1 C     │
   └────────────────────┘
   • Обратный отсчет 20 секунд (настраивается в коде)
   • По завершению автоматически переходит в OTBOR
   • Сохраняет текущую температуру как startTemp

6. OTBOR (Отбор продукта) - ОСНОВНОЙ РЕЖИМ
   ┌────────────────────┐
   │ Otbor T:30.1      *│
   │ Column T:32.5     *│
   └────────────────────┘
   • * в позиции 15 показывает состояние клапана:
     - * есть:  клапан ОТКРЫТ
     - * нет:   клапан ЗАКРЫТ
   • Клапан ОТКРЫВАЕТСЯ если температура НЕ превышает startTemp + g
   • Клапан ЗАКРЫВАЕТСЯ если температура превышает startTemp + g
   • Длинное нажатие: Возврат в WAIT, клапан закрывается

================================================================================
                     АЛГОРИТМ РАБОТЫ КЛАПАНА
================================================================================

В режиме OTBOR контроллер работает по следующему алгоритму:

  1. При входе в режим запоминается startTemp (текущая температура)
  2. Пока T ≤ startTemp + гистерезис → клапан ОТКРЫТ (отбор идет)
  3. Когда T > startTemp + гистерезис → клапан ЗАКРЫТ (отбор остановлен)
  4. При снижении температуры клапан снова открывается

  ПРИМЕР при startTemp=78.0°C и гистерезисе 0.5°C:
    • 78.4°C → клапан ОТКРЫТ
    • 78.6°C → клапан ЗАКРЫТ
    • 78.3°C → клапан ОТКРЫТ

================================================================================
                     ПОДГОТОВКА К РАБОТЕ
================================================================================

1. Подключите оборудование согласно схеме
2. Подайте питание на контроллер
3. Дождитесь загрузки (3 секунды)
4. На дисплее отобразится главный экран с температурой

Перед запуском настройте:
  а) Целевую температуру (SET_TARGET)
  б) Гистерезис (SET_UP) - рекомендуется 0.5°C для точного отбора

================================================================================
                     ПОРЯДОК РАБОТЫ
================================================================================

1. ЗАПУСК СТАБИЛИЗАЦИИ:
   • На главном экране коротко нажмите кнопку
   • Контроллер перейдет в режим STABILIZATION
   • Дождитесь достижения целевой температуры
   • Автоматически запустится таймер на 20 секунд

   ВНИМАНИЕ: В режиме стабилизации контроллер НЕ управляет 
   нагревом! Используйте внешний регулятор мощности.

2. НАЧАЛО ОТБОРА:
   • После таймера контроллер автоматически перейдет в OTBOR
   • Клапан начнет открываться/закрываться по алгоритму
   • Контролируйте процесс по дисплею

3. ЗАВЕРШЕНИЕ РАБОТЫ:
   • Длинное нажатие кнопки в режиме OTBOR
   • Клапан закроется
   • Контроллер вернется на главный экран

================================================================================
                     МЕРЫ БЕЗОПАСНОСТИ
================================================================================

  ВНИМАНИЕ! Контроллер управляет ТОЛЬКО клапаном!
  Нагрев должен контролироваться ОТДЕЛЬНЫМ устройством!

  • Не оставляйте работающее оборудование без присмотра
  • Используйте отдельный термометр для контроля температуры
  • При нештатной ситуации: длинное нажатие кнопки → закрытие клапана
  • Максимальное напряжение на выходе PA1: 3.3В
  • Для управления мощным клапаном используйте релейный модуль

================================================================================
                     СОВЕТЫ ПО ЭКСПЛУАТАЦИИ
================================================================================

1. Для головной фракции:
   • Установите целевую температуру 65-78°C
   • Гистерезис 0.3-0.5°C (точный отбор)

2. Для пищевого спирта:
   • Целевая температура 78-82°C
   • Гистерезис 0.5°C

3. Для хвостовой фракции:
   • Контролируйте температуру в кубе (< 93°C)
   • Следите за скоростью отбора

================================================================================
                     ВОЗМОЖНЫЕ НЕИСПРАВНОСТИ
================================================================================

1. Нет показаний температуры (дисплей показывает 0 или -127):
   • Проверьте подключение датчика DS18B20
   • Проверьте подтягивающий резистор 4.7 кОм

2. Клапан не открывается:
   • Проверьте подключение к PA1
   • Проверьте напряжение на выходе (должно быть 3.3В)
   • Убедитесь что температура в допуске

3. Кнопка не реагирует:
   • Проверьте подключение к PB3
   • Убедитесь что используется INPUT_PULLUP

4. Дисплей не показывает:
   • Проверьте адрес I2C (по умолчанию 0x27)
   • Проверьте подключение SDA/SCL
